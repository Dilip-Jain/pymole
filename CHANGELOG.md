# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0a1] - 2026-10-02

### Changed
- Improved C++ binding compatibility with the MinGW UCRT runtime.
- Added type declarations for the compiled operator module.
- Expanded native binding tests and aligned sparse matrix behavior across backends.
- Included pybind11 in isolated build requirements.

## [0.1.0-alpha] - 2025-09-06

### Added
- Initial release
- Pure Python implementation of mimetic operators
- C++ implementation bindings using pybind11
- Support for gradient, divergence, and Laplacian operators
- Periodic and non-periodic boundary conditions
